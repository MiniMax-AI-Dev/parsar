---
title: 审计与用量
description: 在设置中查看审计事件和模型用量，并定位关联 Run。
---

审计记录用于追踪操作，用量记录用于检查模型消耗。两个入口都在左侧的**设置**页面顶部，所有有效工作区成员均可查看，包括 Viewer（访客）。

## 查看审计

1. 打开**设置 → 审计**。
2. 查看操作时间、操作者、事件和目标资源，使用页面提供的筛选定位记录。
3. 调查单次执行时，也可以打开**运行 → 对应记录 → Audit**（审计），只查看关联该 Run 的事件。

审计记录保留操作发生时的事件，不会因资源当前名称或状态改变而改写。

## 查看用量

打开**设置 → 用量**，页面包含：

| 区域 | 内容 |
| --- | --- |
| 顶部汇总 | Run 数、Input tokens、Output tokens、总成本。 |
| 按模型聚合 | 每个供应商和模型的调用次数、输入、输出和成本。 |
| 最近调用 | 每次调用的时间、Run、供应商、模型、输入、输出和成本。 |

**最近调用 → Run 列**中的 ID 可以点击。点击后进入运行页面，右侧展开对应 Run；没有关联 Run 的记录显示横线。Run 详情本身没有用量标签。

这些数值来自执行器和模型服务上报。没有上报的 Token 或费用会显示为零，不能据此认定服务商没有收费；最终账单以服务商记录为准。

## 查看产物

打开**运行 → 对应记录 → Artifacts**（产物），查看已记录的名称、类型和地址。该标签是产物清单，不是用量明细。分享产物或诊断信息前，检查是否包含秘密、私有代码或个人信息。

参见[查看运行、审批和日志](/zh/runs-approvals-logs)和[安全模型](/zh/security)。
