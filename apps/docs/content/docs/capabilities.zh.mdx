---
title: 能力、Skill 与 MCP
description: 添加可复用的 Skill 和工具服务，并绑定到 Agent。
---

能力让多个 Agent 复用同一组指令或工具。入口是左侧的**能力**，页面提供**本工作区**、**能力市场**、**连接器**和 **Skills** 标签。

## 导入 MCP

1. 打开**能力 → 新建能力 → MCP**。
2. 输入能力名称和可选描述，在配置编辑框粘贴 JSON 或 TOML。可以粘贴完整配置，也可以粘贴内部的 `mcpServers` 对象。
3. 检查解析预览中的服务命令、URL 和环境变量。对以 `$` 开头的环境变量选择现有凭据，或在凭据选择器中创建凭据。
4. 点击**导入**，回到 Agent 的**配置**并绑定这项能力。

本地命令型 MCP 在执行设备上启动，所需命令和依赖必须在该设备上可用。远程 MCP 的地址必须能从执行环境访问。

**能力 → 连接器**提供 MCP 目录；它与左侧**集成**中的聊天机器人是不同入口。

## 导入 Skill

打开**能力 → 新建能力 → Skill**。**粘贴 Markdown** 标签接受带 YAML frontmatter 的完整 `SKILL.md`；等待预览出现后检查名称、描述和指令，再点击**导入**。解析预览是只读的，修改内容需要重新粘贴。

切换到**上传 zip**标签后，将 `.zip` 拖到上传框或点击选择文件，大小上限为 **8 MiB**。等待上传和解析完成，检查 `SKILL.md`、引用文件和脚本的文件树，再点击**导入**。导入不会执行 Skill 文件，失败时修正压缩包后重新选择。

Skill 是可复用的操作指南及其附带资源，不是独立运行的 Agent。安装后仍需绑定到 Agent，再通过一次实际运行确认它被加载。

## 绑定与更新

1. 打开 **Agent → 目标 Agent → 配置**。
2. 添加已启用的能力并配置其需要的凭据。
3. 选择跟随最新版本或固定版本，然后保存。
4. 运行一个只涉及该能力的小任务，在 Run 的 **Steps**（步骤）中查看加载和执行结果。

跟随最新版本会在后续运行中使用新的可用版本；固定版本用于保留确定的内容。更改绑定不会改写过去的 Run。

## 其他能力类型

新建能力只提供 MCP 和 Skill。已有记录还包括：

| 类型 | 用途 |
| --- | --- |
| Plugin | Agent 工具的插件包，例如 Claude Code 插件。 |
| System Prompt | 可复用的指令文本。 |
| Plugin Bundle | Parsar 扩展包，可包含服务端工具、客户端界面和 Skill。 |

这些类型不能通过新建能力的类型选择器直接创建。维护已有记录时使用详情中的版本操作；从能力市场导入时先检查来源、类型和内容。不要把 Plugin 与 Plugin Bundle 当成同一种包。

能力文件默认可保存在 PostgreSQL，不需要为了导入文件而先配置 OSS。插件 CLI 当前的认证限制见[CLI 参考](/zh/cli)。

## 凭据与兼容性

能力需要的秘密应保存在**设置 → 凭据**，通过引用提供，不要放进 Skill 文件或 MCP 普通环境变量文本。个人凭据和组织凭据的区别见[模型与凭据](/zh/models-credentials)。

不同引擎对 MCP、Skill 和插件的支持不同。已导入或已绑定不等于执行成功；查看运行事件中具体的加载错误和缺失凭据。参见[Agent 引擎对照](/zh/agent-tools)。
