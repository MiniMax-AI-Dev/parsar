---
title: 登录与注册
description: 创建首个账号、通过邀请加入工作区，并登录 Parsar。
---

在浏览器打开你的 Parsar 服务地址。新实例展示初始化表单；已经初始化的实例展示登录页。

## 创建第一个账号

1. 填写**你的姓名**、**邮箱**、**密码**和**工作区名称**。
2. 密码至少 8 个字符，并通过表单的密码检查。
3. 点击**创建管理员账号**。

创建成功后自动登录，你成为首个工作区的 Owner。实例已有 Owner 后，初始化入口关闭，其他成员通过邀请加入。

## 通过邀请注册

打开收到的邀请链接，或在登录页点击**注册**，粘贴邀请链接后点击**继续**。

邀请页固定展示受邀邮箱和工作区。填写密码与确认密码，点击**设置密码并加入**，成功后自动进入工作区。邀请链接有效期为 72 小时，已使用、已取消或已过期的链接不能再次使用。

接受邀请会设置受邀邮箱账号的密码，包括已有账号。管理员为已有账号添加成员关系时，可使用**成员 → 邀请新成员 → 已有用户**。详见[成员与角色](/zh/members-roles)。

## 登录与退出

输入邮箱和密码登录。登录页还会列出当前部署已配置的飞书登录入口。

退出时，打开左侧底部的用户菜单，点击**退出登录**。这会撤销当前浏览器会话。会话默认有效期为 30 天，使用过程中不会延长原定过期时间。

## 配置飞书登录

这一步由部署管理员完成，与**集成**中的飞书机器人扫码连接分开：

1. 在飞书开放平台准备登录应用及其 App ID 和 App Secret。申请并发布 `contact:user.id:readonly`、`contact:user.base:readonly`、`contact:user.email:readonly` 权限；登录要求飞书返回用户 ID 和邮箱。
2. 向 Parsar 服务进程传入 `PARSAR_FEISHU_APP_ID`、`PARSAR_FEISHU_APP_SECRET`，并设置 `PARSAR_FEISHU_MOCK=false`。
3. 将 `PARSAR_PUBLIC_URL` 设为用户访问的服务地址。在飞书应用中登记回调地址 `https://你的服务域名/api/v1/auth/feishu/callback`。
4. 使用不同回调地址时，通过 `PARSAR_FEISHU_REDIRECT_URI` 指定同一个地址。
5. 重启服务，再从登录页完成一次飞书授权。

这些值属于服务端部署配置，没有工作区内的登录 Provider 编辑页面。Compose 部署需要把变量加入服务的 `environment`；只追加到 .env 不会自动传入容器。

## 登录问题

| 现象 | 检查与操作 |
| --- | --- |
| 邮箱或密码错误 | 核对邮箱及当前密码；接受过新的邀请后使用邀请页设置的密码。 |
| 返回登录页或接口返回 401 | 重新登录，并检查浏览器是否保存、发送会话 Cookie。 |
| 飞书授权后无法返回 | 核对公共 URL 和飞书登记的回调地址，重新发起登录。 |
| 登录后进入创建工作区页面 | 当前账号没有可访问的工作区，创建工作区或接受邀请。 |
| 能登录但不能使用某个 Agent | 核对工作区角色和 Agent 的访问设置。 |

参见[令牌与凭据](/zh/authentication-tokens)和[部署配置](/zh/configuration)。
