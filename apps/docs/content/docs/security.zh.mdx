使用 Agent 前，确认谁能调用它、任务在哪里执行，以及它能访问哪些工具和凭据。

## 工作区和 Agent 访问

登录确认账号身份，工作区成员关系控制工作区访问，角色控制管理与写入操作。Viewer 不能发送消息、发起运行或处理交互请求。

Agent 的可见性和访问范围独立检查。Owner 和 Admin 管理配置时拥有管理权限，但运行 Agent 时仍需满足它的访问设置。入口见[创建和配置 Agent](/zh/create-agent)。

工作区成员可以读取工作区对话。共享链接只是打开原对话的另一种方式，不会放宽访问权限，也不是私密消息隔离机制。详见[对话与共享对话](/zh/conversations)。

## 执行位置

本地设备上的 daemon 以启动它的操作系统账号执行编程 CLI。Agent 访问文件和网络的范围受该账号及运行环境权限约束。配置工作目录不等于建立文件系统沙盒。

云端隔离使用独立沙盒环境，外部 HTTP Agent 使用对应服务的执行环境。选择能力和凭据前，先在 Agent 详情确认执行位置及引擎。

审批由支持该交互的引擎发起；没有审批卡片不表示所有引擎都会拦截工具操作。引擎支持情况见[Agent 引擎对照](/zh/agent-tools)。

## 凭据与秘密回答

模型和工具凭据在**模型**及**设置 → 凭据**管理，机器人凭据在**集成**管理。服务端加密保存这些 Secret，设备配对令牌与运行凭据则保存哈希用于验证。

秘密回答会被送到等待中的 Agent，保存的交互响应和相关运行、审计事件会脱敏。普通对话消息不是秘密输入框，Agent 后续生成的文本或文件也需要自行检查。详见[令牌与凭据](/zh/authentication-tokens)。

## 停用与移除

- 停用 Agent：停止接收新的运行请求，保留历史记录。
- 移除成员：撤销其工作区成员关系，保留账号与历史记录，不自动停用 Agent 或 Runtime。
- 归档工作区：关闭正常访问，保留历史数据；当前没有界面恢复操作。
- 临时停止设备：在设备上执行 `parsar-daemon stop`。不再使用时，先停止 daemon，再由所有者或管理员在**执行层**删除设备。

取消活动运行时，打开**运行 → 对应记录 → 取消运行**，并确认终态。不要把移除成员当作取消运行操作。

## 审计和部署

**设置 → 审计**查看工作区操作记录，**运行**查看单次执行事件，**设置 → 用量**查看引擎上报数据。

自托管部署使用 HTTPS，保留安装器生成的稳定密钥，并将数据库与加密主密钥安全备份。主密钥丢失后，已有密文无法解密。部署步骤见[部署配置](/zh/configuration)。
