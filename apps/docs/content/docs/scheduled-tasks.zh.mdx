---
title: 定时任务
description: 用频率、时间和时区表单安排 Agent 执行，并查看运行结果。
---

定时任务按计划把保存的 Prompt 交给一个 Agent。每次触发都会创建独立的对话和 Run，历史结果保留在**对话**和**运行**中。

## 创建任务

所有者、管理员和成员可以管理定时任务，访客只能查看。

1. 打开左侧的**定时任务**，点击右上角**新建任务**。
2. 填写**任务名**，在**执行 Agent**中选择已启用的 Agent。
3. 填写 **Prompt**，描述每次执行要完成的工作。
4. 选择**频率**和时间。普通计划使用表单，不需要填写 cron。
5. 选择**时区**，检查**频率预览**后点击**保存**。

| 频率 | 需要选择的时间 |
| --- | --- |
| 每天 / 工作日 | 时间；工作日指周一至周五。 |
| 每周 | 星期和时间。 |
| 每月 | 每月第几天和时间。 |
| 每小时 | 分钟。 |
| 自定义 | 五字段 cron 表达式，依次为分、时、日、月、周。 |

例如每天北京时间 09:00 执行：选择**每天**、时间 **09:00**、时区 **Asia/Shanghai**。表格中的 `0 9 * * *` 是系统生成的计划表示。

新任务保存后默认启用，列表显示**下次运行**。时区初始值来自浏览器，请在保存前确认。编辑已有任务可以修改名称、Prompt 和计划，但不能更换执行 Agent。

## 立即运行与查看结果

1. 点击任务行右侧的播放图标，悬停提示为**立即运行**。
2. 页面显示**已触发一次运行**，表示执行请求已创建，不表示 Agent 已完成。
3. 打开左侧的**运行**，按执行 Agent 和刚才的时间找到新记录，点击查看右侧 **Steps**（步骤）。
4. 执行结束后，Run 显示**已完成**、**失败**、**已取消**或**已中断**。点击**打开对话**阅读回复。

定时任务列表当前不会持续轮询执行结果。停留在此页时，状态图标会保留上次加载时的值；刷新页面后读取最新状态。图标上的“运行中”不能单独用来判断执行卡住。

## 管理计划

任务行提供**编辑**、**立即运行**、启用或停用、**删除**操作。停用会停止后续自动触发，仍可手动立即运行；删除任务保留历史运行记录。新建表单没有“保持停用”选项，需要先保存再停用。

自动调度和**立即运行**都会阻止同一任务重叠执行。上一轮仍在排队或运行时，再次手动触发会提示 `a run is already active for this task`（该任务已有活动运行），不会创建新 Run。等待当前运行结束，或在 Run 详情取消后再触发。手动执行不会改变下次计划时间。

调度器在下一次到期时检查上一轮结果：失败、取消或中断增加连续失败计数，完成则清零；达到 **5 次**后自动停用任务。手动触发不会即时修改该计数。排除错误后，再重新启用计划。

## 长时间运行时检查什么

查看对应 Run 的最新步骤、收件箱中是否有待处理请求，以及设备是否在线。真实 Agent 需要等待模型和工具完成，测试用固定回复不能代表真实任务的耗时。没有新事件时，从[故障排查](/zh/troubleshooting)中的运行检查开始。
