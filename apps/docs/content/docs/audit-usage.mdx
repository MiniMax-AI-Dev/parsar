title: Audit and usage
description: Inspect audit events and model usage in Settings, then open the related Run.
---

Audit records track operations. Usage records track reported model consumption. Both are tabs at the top of **Settings**, visible to all active workspace members, including viewers.

## Inspect audit events

1. Open **Settings → Audit**.
2. Inspect the time, actor, event, and target resource, using the available filters to locate a record.
3. For one execution, open **Runs → the record → Audit** to see events associated with that Run.

Audit records preserve events as they occurred; changing a resource's current name or status does not rewrite those events.

## Inspect usage

Open **Settings → Usage**:

| Area | Contents |
| --- | --- |
| Summary | Run count, input tokens, output tokens, and total cost. |
| By model | Calls, input, output, and cost for each provider and model. |
| Recent calls | Time, Run, provider, model, input, output, and cost for each call. |

IDs in **Recent calls → Run** are clickable. Clicking one opens Runs with that Run expanded on the right. Records without a related Run show a dash. Run details have no Usage tab.

Values come from executor and model-provider reports. Unreported token counts or costs show zero; that does not establish that the provider charged nothing. Use the provider's records for final billing.

## Inspect artifacts

Open **Runs → the record → Artifacts** to see recorded names, types, and addresses. This is an artifact inventory, not usage detail. Check artifacts and diagnostics for secrets, private code, and personal information before sharing them.
