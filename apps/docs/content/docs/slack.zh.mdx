---
title: Slack
description: 在集成页面配置工作区 Slack 机器人的 Socket 模式连接。
---

入口：**左侧集成 → Slack**。点击平台行后，在右侧填写配置。只有工作区所有者和管理员可以编辑。

## 准备 Slack 应用

在 [Slack 应用管理](https://api.slack.com/apps)中创建应用，启用 Socket Mode，并安装到要使用的 Slack 工作区。准备以下值：

| Parsar 字段 | Slack 中的来源 |
| --- | --- |
| App ID | Basic Information 中的 App ID。 |
| Bot Token | OAuth & Permissions 中的 Bot User OAuth Token，前缀为 `xoxb-`。 |
| App-Level Token | Basic Information 中生成的 App-Level Token，授予 `connections:write`，前缀为 `xapp-`。 |

按 Slack 应用设置授予收发消息权限、订阅需要的消息事件，并把机器人加入要使用的频道。

## 保存连接

1. 打开**集成 → Slack**。
2. 填写 App ID 和 Bot Token，**事件模式**选择 **Socket 模式**。
3. 填写 App-Level Token，打开**启用 Slack 机器人**并保存。
4. 确认列表显示**已启用**。关闭启用开关时，按钮为**保存草稿**。

当前接收端只为 Socket 模式启动连接。表单虽有 **Events API** 选项，但当前服务没有对应的 Slack HTTP 事件接收入口，不要选用它配置可运行的集成。

## 验证与限制

服务端会自动读取已启用的工作区连接，不需要再设置 `PARSAR_SLACK_CONNECTORS`。部署必须已有 `PARSAR_MASTER_KEY`，且允许出站连接 Slack。

发送者还需要平台身份映射和工作区访问权限。当前没有 Slack 自助账号绑定入口，需先由部署管理员准备映射，再在 Slack 中验证消息，最后到 Parsar 的**运行**检查结果。

令牌更换或暂停使用时，回到同一面板更新后保存。参见[聊天集成](/zh/integrations)。
