Parsar is a shared Agent workspace for teams. Configure models and execution devices, talk to Agents, respond to approvals, and inspect each run's results.

## Get started

- Already have a Parsar workspace? Follow the [quickstart](/quickstart) to configure a model, connect a device, and start your first conversation.
- Need to deploy the server? Use the [self-host quickstart](/self-host-quickstart) to install with Docker Compose.
- Want to understand the workflow first? Read [Core concepts](/concepts) and [How Parsar works](/how-parsar-works).

## Deployment and maintenance

Deployment administrators can read [Deployment configuration](/configuration), [Login and registration](/authentication), and [Security model](/security). Start with [Troubleshooting](/troubleshooting) for execution problems.

Parsar is currently in Alpha. This guide follows current product entry points and identifies creation options that are not yet available on their respective pages. The API reference is at `/docs` on your Parsar server.
