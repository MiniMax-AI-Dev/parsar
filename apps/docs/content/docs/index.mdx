Parsar turns your team's intent into an observable agent run. People create a conversation or task, choose an Agent, and receive progress and results back in the same workspace.

## What Parsar provides

| Capability | What it means |
| --- | --- |
| Team control plane | Workspaces, members, permissions, conversations, and durable history live together. |
| Pluggable execution | Agents run through a paired `parsar-daemon`, a sandbox, or an HTTP Agent connector. |
| Auditable runs | Every run records status, events, output, artifacts, usage, and failures. |
| Self-hosted operation | Your code, credentials, database, and runtime can stay on infrastructure you control. |

## Product status

Parsar is alpha software. APIs, schemas, and configuration can change between releases. Treat the repository and the generated OpenAPI contract as the source of truth for the version you deploy.
