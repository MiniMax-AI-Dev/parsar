---
title: Microsoft Teams
description: 配置 Teams 机器人凭据和部署端消息接收地址。
---

入口：**左侧集成 → Microsoft Teams**。所有者和管理员填写工作区机器人凭据；部署管理员负责启用服务端接收地址。

## 部署前置条件

当前 Teams 接收端仍需要部署管理员在 Parsar 服务进程中设置 `PARSAR_TEAMS_CONNECTORS=true` 和稳定的 `PARSAR_MASTER_KEY`，重启服务后才会接收工作区机器人的消息。仅在 Web 表单中开启机器人不足以启用接收端。

在 Azure Bot 配置中，将 Messaging endpoint 设置为：

```text
https://你的Parsar域名/api/teams/messages
```

该地址必须能通过公网 HTTPS 访问。使用 Compose 时，额外服务端变量需要加入服务的环境配置，仅向未引用该变量的 .env 文件追加一行不会传入容器。

## 填写工作区配置

在 [Azure 门户](https://portal.azure.com)注册应用和 Bot，启用 Teams 渠道，然后回到 Parsar：

1. 打开**集成 → Microsoft Teams**。
2. **App ID**填写应用程序（客户端）ID。
3. **应用密码**填写“证书和密码”中新建客户端密码的**值**，不是密码 ID。
4. 单租户应用填写**租户 ID**；多租户配置留空。
5. 打开**启用 Teams 机器人**并保存，确认列表显示**已启用**。

## 验证与限制

发送者需要平台身份映射及工作区权限。当前没有 Teams 自助账号绑定页面，需要部署管理员先准备映射。将 Bot 添加到 Teams 后发送请求，在 Parsar 的**运行**确认对应记录。

收到配置成功但没有消息时，先检查上述接收端是否已启用、Azure 的 Messaging endpoint 是否正确，再检查身份映射。参见[聊天集成](/zh/integrations)和[部署配置](/zh/configuration)。
