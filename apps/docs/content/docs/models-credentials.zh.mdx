title: 模型与凭据
description: 添加模型、测试接口，并管理个人和组织凭据。

模型记录服务地址、模型标识和 API 协议。凭据用于验证调用权限。先配置并测试模型，再把它选为 Agent 使用的模型。

模型目录由整个 Parsar 实例共享。切换工作区后看到的是同一批模型记录；修改模型也会影响其他工作区中使用它的 Agent。

## 添加模型

1. 打开左侧的**模型**，点击**新建模型**。
2. 选择服务商，填写模型名称与 Model Key；Model Key 应使用服务商实际接受的标识。
3. 确认服务地址和 API 协议。一个模型支持多个接口时，分别检查各协议对应的地址。
4. 选择凭据模式：使用共享 Key 时填写 API Key；使用个人凭据模式时选择所需凭据类型，并准备个人凭据。
5. 保存模型。

编辑已有模型可以修改地址和模型信息，但不能切换凭据模式。要更换模式，创建另一条模型记录。

## 测试模型

在模型列表找到记录，使用**测试连接**操作。测试诊断展示各接口的结果，查看错误信息确认是地址、协议、认证还是模型标识问题。

连接测试成功后，在 **Agent → 新建 Agent**中选择该模型。已有 Agent 则打开详情，点击底部的**编辑**，选择模型后**保存**。模型测试和完整 Agent 运行是两次不同的验证：还需要执行设备和编程 CLI 可用。

## 为 Agent 绑定凭据

当前**新建 Agent**表单固定创建公开 Agent，**调用者各自的 API key**不可选。自带共享 Key 的模型可以直接选用；选择引用凭据的模型时，在 **Model 凭据**中选择**使用共享 API key**，再选择已有共享密钥或在表单中新建一条。

只准备个人凭据不足以完成这个新建流程。已有的非公开 Agent 可以使用调用者各自的个人凭据，每位调用者都需要提供模型要求的凭据类型。

## 管理凭据

### 个人凭据

打开**设置 → 凭据 → 我的个人凭据**，点击**添加凭据**，选择凭据类型并填写对应字段。已有记录提供**编辑**和**删除**，更换凭据值时使用编辑。这些凭据属于当前账号，可以跨工作区复用，其他成员不能读取。

### 组织共享凭据

工作区所有者和管理员打开**设置 → 凭据 → 组织共享凭据**。点击**添加 API Key**，选择**运行环境**或**自定义 API**用途，填写**名称**、**服务 / Provider**和 **API Key**，然后保存。

此标签没有通用的密钥编辑操作。模型密钥行提供**前往 Models**，在模型的编辑表单中更新密钥；工作区 E2B Key 在**执行层**管理。Agent 或能力绑定的共享密钥需要更换时，先创建替代密钥、修改对应资源的凭据绑定并验证一次 Run，再禁用旧密钥。

保存后只展示元数据或掩码；掩码不是可再次提交的原始密钥。不要把 API Key 放进 Prompt、Skill 或普通对话。

能力要求个人凭据时，每位使用者需要准备自己的凭据；管理员保存一条组织凭据不等于为所有账号完成个人认证。
