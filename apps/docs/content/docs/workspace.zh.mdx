title: 工作区
description: 创建、切换和管理团队共享的工作区。

工作区集中保存团队成员、Agent、对话、运行、能力、设备和集成。左上角 **Parsar / 工作区名称** 是工作区切换器。

[模型目录](/zh/models-credentials)由整个 Parsar 实例共享，切换工作区不会得到独立的模型目录。

## 创建工作区

1. 点击左上角的工作区名称。
2. 选择**新建工作区**。
3. 填写**名称**，选择**私有**或**公开**可见性。
4. 点击**创建**。

创建者成为该工作区的 `owner`。首次登录且尚未加入工作区的账号，会先进入引导页面；该页面只填写工作区名称，创建的是私有工作区。创建后可通过工作区切换器修改可见性。

私有工作区通过邀请或管理员添加成员；公开工作区还会出现在已登录用户的工作区发现列表中。公开可见性不开放其中的对话和运行记录，申请人仍需获准加入。

## 切换或申请加入

工作区切换器列出你已经加入的工作区，点击名称即可切换。切换只改变当前查看的范围，不会移动或复制数据。

在切换器的发现区域选择公开工作区，提交加入申请；填写申请理由是可选项。申请处于待处理状态时可点击**撤回**。工作区的 Owner 或 Admin 在左侧**成员**页面的**待审批**区域处理申请。

## 修改名称和可见性

Owner 和 Admin 打开工作区切换器，点击目标工作区旁的铅笔图标（**重命名工作区**），修改名称或可见性后保存。

## 归档工作区

Owner 和 Admin 在同一行点击归档图标（**归档工作区**），确认后归档。

归档后，工作区从切换器和发现列表移除，正常访问被关闭，历史数据保留。当前页面没有恢复归档的操作。工作区存在被其他工作区使用的能力市场依赖时，服务端会拒绝归档。

## 成员与资源访问

工作区成员关系与 Agent 的访问范围分别检查。成员需要满足 Agent 的访问设置才能调用它；Viewer 只能查看，不能发起运行或处理审批。

当前工作区菜单没有“离开工作区”入口。移除成员在**成员**页面操作，具体权限见[成员与角色](/zh/members-roles)。
