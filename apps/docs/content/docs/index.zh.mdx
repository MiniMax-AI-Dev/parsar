Parsar 是团队共享的 Agent 工作台。你可以配置模型和执行设备，与 Agent 对话，处理审批，并查看每次运行的结果。

## 开始使用

- 已有 Parsar 工作区：[快速上手](/zh/quickstart)，配置模型、连接设备并完成第一次对话。
- 需要部署服务：[自托管快速上手](/zh/self-host-quickstart)，通过 Docker Compose 安装。
- 想先了解工作流程：[核心概念](/zh/concepts)和[Parsar 的工作方式](/zh/how-parsar-works)。

部署管理员可以阅读[部署配置](/zh/configuration)、[登录与注册](/zh/authentication)和[安全模型](/zh/security)。遇到运行问题时，从[故障排查](/zh/troubleshooting)开始。

Parsar 当前处于 Alpha 阶段。本指南按当前产品入口组织，尚未开放的创建选项会在对应页面明确标注。API 参考位于 Parsar 服务地址下的 `/docs`。
