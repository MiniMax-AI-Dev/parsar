---

Parsar 把团队的意图转成可观察的 Agent 运行。成员在工作区里创建对话或任务，选择 Agent，并在同一个上下文中收到进度和结果。

## Parsar 能做什么

| 能力 | 含义 |
| --- | --- |
| 团队控制面 | 工作区、成员、权限、对话和持久化历史集中管理。 |
| 可插拔执行 | Agent 可以通过配对的 `parsar-daemon`、沙盒或 HTTP Agent 连接器运行。 |
| 可审计运行 | 每次运行都记录状态、事件、输出、产物、用量和失败原因。 |
| 自托管 | 代码、凭据、数据库和运行环境可以保留在你控制的基础设施中。 |

## 产品状态

Parsar 当前处于 Alpha 阶段。不同版本之间的 API、Schema 和配置可能变化。部署哪个版本，就以该版本仓库和生成的 OpenAPI 契约为准。
