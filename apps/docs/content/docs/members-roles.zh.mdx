入口是左侧的**成员**。页面展示当前成员、待审批的加入申请和待处理邀请。

## 角色与权限

| 操作 | Owner（所有者） | Admin（管理员） | Member（成员） | Viewer（访客） |
| --- | --- | --- | --- | --- |
| 查看工作区 | 是 | 是 | 是 | 是 |
| 运行有权使用的 Agent、处理交互请求 | 是 | 是 | 是 | 否 |
| 创建邀请链接 | 是，可选角色 | 是，可选角色 | 是，只能邀请 Member | 否 |
| 添加已有用户、审批加入申请 | 是 | 是 | 否 | 否 |
| 修改非 Owner 成员角色、移除非 Owner 成员 | 是 | 是 | 否 | 否 |
| 修改和归档工作区 | 是 | 是 | 否 | 否 |

创建邀请和添加已有用户的角色选项包含 Owner、Admin、Member、Viewer。新表单默认选中 Member。

已有 Owner 的角色不能在成员页修改，也不能从这里移除。已有成员的角色修改不能提升为 Owner，当前界面没有所有权转让流程。Agent 访问权限独立于成员角色，Owner 和 Admin 发起运行时也会接受检查。

## 邀请新成员

1. 打开**成员 → 邀请新成员**。
2. 在**邀请链接**标签填写邮箱和可选姓名。
3. Owner 和 Admin 选择角色；Member 创建的邀请固定为 Member。
4. 点击**创建邀请**，再点击**复制邀请链接**，将链接发送给受邀者。

链接有效期为 **72 小时**，接受一次后失效。受邀者打开链接，核对工作区和邮箱，填写密码与确认密码，再点击**设置密码并加入**。

邀请页面不要求先登录。该邮箱已有账号时，会加入原账号，并将邮箱登录密码更新为本次填写的密码。为已有账号添加工作区成员关系而不改密码时，使用下面的**已有用户**入口。

## 添加已有用户

Owner 和 Admin 打开**成员 → 邀请新成员 → 已有用户**，搜索姓名或邮箱，选择用户和角色，再点击**添加**。选中的用户直接成为工作区成员，无需接受邀请链接。

## 管理邀请与加入申请

- **待处理邀请**：复制链接、修改邀请角色或取消邀请。取消后链接立即失效。Owner 和 Admin 管理工作区邀请；Member 只能查看和取消自己创建的邀请，不能修改角色。
- **待审批**：Owner 和 Admin 点击申请旁的**同意**或**拒绝**。被拒绝的申请人可以重新申请。

## 修改角色或移除成员

Owner 和 Admin 使用成员行右侧的角色图标修改非 Owner 成员的角色，或点击移除图标并确认。

移除操作撤销该用户在当前工作区的成员关系，不删除账号、历史对话、运行或审计记录，也不会自动停止其创建的 Agent 和 Runtime。要阻止新的运行请求，需另行停用 Agent；停止或移除设备见[Runtime 与执行位置](/zh/runtimes)。

参见[工作区](/zh/workspace)和[安全模型](/zh/security)。
