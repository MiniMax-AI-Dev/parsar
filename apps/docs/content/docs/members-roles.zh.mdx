---
title: 成员与角色
description: 管理工作区成员、邀请、加入申请和角色边界。
---

每个 active 工作区成员都有一个角色。Parsar 当前支持 `owner`、`admin`、`member` 和 `viewer`。

角色和成员状态是两个字段。成员状态可以是 `pending`、`active` 或 `rejected`；只有 `active` 行会参与访问检查。`viewer` 明确是只读角色；`member` 是否能使用资源还要经过 Agent 自身的访问策略。

## 角色概览

| 操作 | owner | admin | member | viewer |
| --- | --- | --- | --- | --- |
| 查看工作区 | 是 | 是 | 是 | 是 |
| 使用 Agent Access 允许的资源 | 是 | 是 | 是 | 否 |
| 邀请或管理成员 | 是 | 是 | 否 | 否 |
| 修改工作区设置 | 是 | 是 | 否 | 否 |
| 修改 owner | 是 | 否 | 否 | 否 |
| 删除或归档工作区 | 是 | 否 | 否 | 否 |

`viewer` 在工作区层面是只读角色。每次运行 Agent 时仍会单独检查 Agent Access，owner 或 admin 也不能绕过 Agent 的访问范围。

## 邀请成员

1. 打开**设置 → 成员**。
2. 点击**邀请成员**。
3. 输入邮箱和可选的展示名称。
4. 选择角色并提交。

Owner 和 admin 可以授予 `admin`、`member` 或 `viewer`。只有 Owner 能提升其他 Owner 或移除 Owner，服务端始终保留至少一个 Owner。邀请不能直接创建 owner 成员关系。

## 加入申请

公开工作区可以接收自助加入申请。Owner 和 admin 可以在**成员**页面查看待处理申请并批准或拒绝。申请人可以撤回自己的待处理申请。被拒绝的成员记录会保留用于审计，不会阻止之后重新申请。

## 修改角色或移除成员

Owner 和 admin 可以修改 `admin`、`member` 和 `viewer`。涉及 owner 的提升、降级或移除只能由另一位 owner 执行。系统始终要求工作区至少保留一名 owner。

移除成员会立即撤销其工作区访问权限。该成员历史创建的 Conversation、Run、消息和审计记录仍保留在工作区中。该成员拥有的 Runtime 和 Agent 绑定会按照资源生命周期规则停用或解除绑定，确认前请阅读界面提示。

## 邀请排查

- 没有邀请按钮时，确认当前账号是 owner 或 admin，并且已经选择工作区。
- 受邀者无法加入时，确认登录邮箱与邀请邮箱一致。
- 公开工作区没有出现在发现列表时，检查工作区可见性和服务端注册策略。
- 角色修改似乎没有生效时，刷新成员页面；API 会立即执行角色校验。
