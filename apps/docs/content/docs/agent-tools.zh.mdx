Agent Connector 描述 Parsar 如何派发工作；agent kind 描述 Runtime 内实际运行的工具或适配器。区分这两个概念有助于定位 Provider 错误。

## Agent Daemon 支持的工具类型

`config.agent_kind` 只接受四个值：`claude_code`、`codex`、`opencode`、`pi`。daemon 连接时才会发现工具是否可用及其版本；只修改 Agent 配置不会自动安装工具。

| 适配器 | 流式输出 | 权限请求 | 用量 | 恢复 |
| --- | ---: | ---: | ---: | ---: |
| `claude_code` | 是 | 是 | 是 | 是 |
| `codex` | 是 | 是 | 是 | 是 |
| `opencode` | 是 | 未声明支持 | 是 | 未声明支持 |
| `pi` | 是 | 否（`--no-approve`） | 是 | 是 |

## 在执行机器上安装

1. 按工具官方说明安装 CLI；
2. 使用运行 `parsar-daemon` 的操作系统用户完成认证；
3. 确认可执行文件位于 `PATH`，或在支持的配置中填写绝对路径；
4. 配对 daemon，确认 Runtime 在线；
5. 发送一个小范围 Prompt，并在 Runtime 快照中确认实际适配器。

共享机器不要直接使用个人账号认证，除非团队已经明确账号归属和审计影响。

## Capability 兼容性

Parsar 会根据目标适配器渲染 Capability。对某个工具有效的 Skill、MCP、Plugin 或 System Prompt 不一定被另一个工具支持。遇到不兼容时，Parsar 会记录禁用或跳过提示，不会假装工具已生效。

Run 报告能力不支持时，先检查 agent kind、能力类型、版本和所需凭据，再修改 Agent Prompt。

## Provider 错误分类

| 类别 | 首要检查 |
| --- | --- |
| 找不到可执行文件 | daemon 主机上的安装和 `PATH` |
| 认证或配额失败 | 工具登录状态和 Provider 账号 |
| 能力不支持 | 适配器兼容性和 Capability 版本 |
| 网络失败 | daemon 出站网络和 Provider 端点 |
| 配置无效 | Agent 模型、Connector、Runtime 和凭据绑定 |
