---

这篇指南带你在 Parsar 中完成一次真实的 Agent 运行。已经有可登录的 Parsar 服务时，从配置模型开始。

## 1. 打开 Parsar

还没有服务时，按[自托管快速上手](/zh/self-host-quickstart)安装。默认访问地址是 `http://127.0.0.1:18080`；远程部署使用管理员提供的地址。

首次打开全新实例时，完成初始化表单，创建账号和工作区。已有工作区时，登录并在左上角选择它。

以下配置步骤需要工作区所有者或管理员权限。成员可以直接使用管理员已配置好的 Agent 开始对话。

## 2. 配置模型

打开左侧**模型 → 新建模型**，填写服务商、模型标识和 API 地址。首次运行选择共享 Key 模式并填写有效的 API Key。保存后执行模型的**测试连接**，检查测试结果。完整字段说明见[模型与凭据](/zh/models-credentials)。

## 3. 准备执行设备

打开左侧的**执行层**。默认 Compose 部署自带本地 Runtime；确认它在线并提供要使用的引擎。

要使用自己的电脑，点击**接入新设备**，输入设备名称，生成连接命令并在已安装 CLI 的电脑上执行。详细步骤见[安装 Agent Runtime](/zh/install-runtime)。

## 4. 创建 Agent

1. 打开 **Agent → 新建 Agent**，填写名称。
2. 选择**本地设备**，选择 Claude Code、Codex 或 pi。
3. 选择支持该引擎的在线设备和刚配置的模型。
4. 本地项目需要指定目录时填写绝对路径，例如 `/home/me/projects/demo`。这是执行设备上的路径。
5. 保存 Agent。能力可以在首次运行成功后再添加。

## 5. 发送第一条消息

点击 Agent 的**聊一下**操作，发送：`只回复 OK，不使用工具。`

回复出现在对话时间线中。需要你确认操作或回答问题时，在请求卡片或左侧**收件箱**完成处理。

## 6. 确认结果

打开左侧**运行**，点击刚创建的记录。状态为**已完成**后，用底部的**打开对话**检查回复。**Steps**（步骤）查看运行事件，**设置 → 用量**查看模型消耗。

没有回复时，先查看 Run 的错误和步骤，再检查执行设备和模型；不要仅凭设备在线判断配置成功。
